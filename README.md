# Python Beginner Projects

Welcome to the **Python Beginner Projects** repository! This collection contains 5 mini-projects designed to strengthen core Python programming concepts, including loops, functions, data structures, conditional logic, and file I/O operations.

## 🚀 Projects Overview

1. **Number Guessing Game (`01_number_guessing.py`)**
   - **Concepts:** `random` module, `while` loops, conditional logic, exception handling (`try-except`).
   - **Description:** An interactive console game where the user tries to guess a randomly generated number within a limited number of attempts.

2. **Rock, Paper, Scissors (`02_rock_paper_scissors.py`)**
   - **Concepts:** Lists, string manipulation, user input validation, game score tracking.
   - **Description:** A classic decision-making game played against the computer with score tracking and quit options.

3. **Calculator (`03_calculator.py`)**
   - **Concepts:** Functions, return statements, mathematical operations, edge-case validation (division by zero).
   - **Description:** A modular command-line calculator performing basic arithmetic operations.

4. **Password Generator (`04_password_generator.py`)**
   - **Concepts:** `string` and `random` modules, list shuffling, security constraints.
   - **Description:** Generates strong, randomized passwords containing uppercase/lowercase letters, digits, and special symbols based on user-defined length.

5. **To-Do List Application (`05_todo_app.py`)**
   - **Concepts:** Dictionaries, lists, JSON file handling (`json.dump` / `json.load`), CRUD operations.
   - **Description:** A persistent task management app that allows users to add, view, complete, and delete tasks with data saved to a local JSON file.
